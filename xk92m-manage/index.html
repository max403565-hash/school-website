Repository Authentication

Authenticate using a scoped GitHub Fine-Grained Personal Access Token (PAT). This token is stored only in this browser's localStorage and never transmitted to any third-party server.

How to create your staff token:
1. On GitHub, go to Settings > Developer Settings > Personal Access Tokens > Fine-Grained Tokens.
2. Set repository access to Only Selected Repositories (select this school repository).
3. Under Permissions, grant Contents: Read and write.
4. Set expiration to 6–12 months, paste token below, and click Save.
