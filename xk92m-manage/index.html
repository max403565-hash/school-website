📦 Import Site (Folder or Multiple Files)

Upload an entire website folder or select multiple files (HTML, CSS, JS, images, PDFs) from your computer. Files are analyzed against your live GitHub repository and committed directly as one atomic commit.

📥 Export / Offline Copy

Download the entire current website as a ZIP file to inspect or edit offline.

💡 Editing offline with VS Code & Live Server:
  1. Extract the downloaded ZIP archive into a folder on your computer.
  2. Open Visual Studio Code and choose File → Open Folder... to open the extracted folder.
  3. Install the Live Server extension in VS Code. Right-click index.html and choose "Open with Live Server" to test your edits locally with live reload.
  4. When you are finished editing, return here to the Import Site tab and choose Option A: Choose Entire Website Folder to import your changes back to GitHub in a single commit!
🛡️ Protected System Paths: Files inside xk92m-manage/ (admin panel) and .github/ are strictly protected. They can never be written, overwritten, renamed, or deleted through Site Import.
